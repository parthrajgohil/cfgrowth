# McElroy Manufacturing, Inc.  ·  Fit: A (segment 2)  ·  Researched: 2026-10-06

## Snapshot
- **What they make:** thermoplastic (HDPE) pipe fusion machines and fintube equipment. The TracStar
  iSeries (630i/900i/1200i) uses the **FusionGuide** control system with remote diagnostics over the
  machine's CAN traffic; **DataLogger** tablets record each joint (job, operator, GPS) to **The Vault**
  cloud (19,000+ records for the iSeries alone) [1][2].
- **HQ / region:** Tulsa, Oklahoma, US (four Tulsa-area campuses) [3].
- **Size:** ~370 employees (2022-23 statement) [3]. Current figure unverified.
- **Ownership:** second-generation family-owned, founded 1954 [3][4].
- **Website:** https://www.mcelroy.com
